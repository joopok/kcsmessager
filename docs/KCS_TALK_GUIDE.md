# KCS Talk 2.0 사용 가이드

카카오톡 PC 버전의 대화·일정 기능을 구현한 사내 메신저입니다.
설계/프로토콜 명세: `claudedocs/KAKAO_FEATURE_SPEC.md`

카카오톡 2024~2026 기능 조사와 반영 현황: `claudedocs/KAKAO_2025_RESEARCH.md`

## 직접 확인하는 방법 (3가지)

```bash
python3 scripts/demo.py                    # ① 시연: 서버 + 데모 데이터 + 클라이언트 2개가 바로 뜸 (Ctrl+C로 종료)
python3 scripts/demo.py --clients 3        #    클라이언트 3개 / --users 이름1,이름2 로 사용자 지정
python3 scripts/demo.py --headless-check   # ② 화면 없이 26개 핵심 기능을 실제 서버로 점검해 ✓/✗ 표 출력
python3 scripts/verify_features.py         # ③ 전체 테스트(401개)를 기능 69개별 PASS/FAIL 표로 → claudedocs/FEATURE_VERIFICATION.md
```
앱 안에서는 **더보기 → 기능 둘러보기**: 기능 72개 목록, [해보기] 버튼으로 해당 화면 바로 열기, 체크 표시, '검증 결과' 탭.

## v3 기능 (카카오톡 조사 결과 전부 반영)
| 기능 | 사용법 |
|---|---|
| 비밀채팅 | 친구 우클릭 → 비밀채팅. X25519+AES-GCM 종단간 암호화, 키는 이 PC에만(`~/.kcs_messenger/keys`), 서버엔 암호문만 |
| 보이스톡 · 페이스톡 · 보이스룸 | 채팅방 헤더 📞 → 보이스톡 / 페이스톡(최대 10명, 화면 공유, 배경 흐림) / 보이스룸(진행자·스피커·리스너, 손들기, 48시간 자동 종료). 보이스톡 녹음·자동 녹음(더보기) |
| 펑 | 친구 탭 맨 위 '펑' 줄 → + 로 24시간 스토리 올리기, 친구 펑 보기, 내 펑은 본 사람 목록 |
| 멀티프로필 | 더보기 → 멀티프로필: 친구마다 다른 이름·상태메시지·사진 |
| 친구 숨김 · 차단 | 친구 우클릭 → 숨기기/차단, 더보기 → 친구 관리에서 해제 (차단하면 상대 메시지가 오지 않음, 상대는 모름) |
| 잠금모드 | 더보기 → 잠금모드: 4자리 PIN, N분 무입력 시 회사 로고 잠금 화면, 잠금 중 알림 내용 숨김 |
| 키워드 알림 | 더보기 → 키워드 알림: 알림 끈 방이어도 키워드가 들어오면 알림 + 말풍선 강조 |
| 채팅방별 알림 | 채팅방 메뉴 → 알림 설정: 모든 메시지 / 멘션만 / 끄기 |
| 안 읽은 메시지 아이콘 깜박임 | 안 읽은 메시지가 있는 동안 트레이·Dock(작업 표시줄) 앱 아이콘 전체가 켜졌다 꺼졌다 깜박이고 다 읽으면 멈춤(알림 끈 방 제외). 더보기 → 안 읽은 메시지 아이콘 깜박임으로 끄기, '동작 줄이기'면 깜박이지 않고 흐린 아이콘으로 표시. macOS Dock 에는 'Python' 대신 'KCS Talk'(런처도 'KCS Talk')로 표시 |
| 말풍선 꾸미기 | 더보기 → 말풍선 꾸미기: 7가지 스타일 |
| 사다리 게임 | 채팅방 입력창 도구 🪜 → 참가자·결과 입력, 모두 같은 사다리·결과 |
| 톡게시판 | 채팅방 도구/메뉴 → 게시판: 글·댓글 |
| 오픈채팅 | 채팅 탭 # 버튼 → 찾기(검색·닉네임으로 참여) / 만들기 |
| 톡서랍 | 채팅 탭 서랍 버튼 → 모든 채팅방의 사진·파일·링크 |
| 받은 파일 보관 기간 | 기본 90일(`--retention-days`), 파일 카드에 보관 기한 표시, 지나면 만료 |
| 번역 | 사용자 요청으로 제외 |

참고: 페이스톡 카메라는 macOS 설정 → 개인정보 보호 및 보안 → 카메라에서 터미널(또는 Python) 허용이 필요합니다.

## v4 기능 (카카오톡 2026 업데이트 반영)

| 기능 | 쓰는 법 |
|---|---|
| 대화 요약 | 채팅방 메뉴(☰) → 대화 요약. 안 읽은 메시지가 20개 이상이면 방 위에 '대화 요약 보기' 칩이 뜹니다. Claude를 쓸 수 없으면 결정·요청·질문 문장을 뽑아 요약합니다 |
| 공감 72종 | 말풍선 우클릭 → 공감 → 더 많은 공감…. 말풍선당 30종까지, 6종이 넘으면 +N |
| 음성메시지 | 입력창 ＋ → 음성메시지 → 녹음 → 보내기 (최대 5분). 받은 말풍선의 ▶로 재생 |
| 연락처 보내기 | 입력창 ＋ → 연락처 보내기. 받은 카드에서 1:1 채팅·프로필 |
| '통화' 폴더 | 채팅 탭 칩 줄의 '통화'. 통화 기록과 부재중(빨간색)을 모아 봅니다 |
| 대화 내용 저장 | 채팅방 메뉴(☰) 또는 채팅 목록 우클릭 → **대화 내용 저장…** → 형식(텍스트 .txt = 카카오톡 PC 형식 · 엑셀용 표 .csv · 사진·파일 포함 .zip)과 기간(전체 · 오늘 · 최근 7일 · 최근 30일 · 기간 지정)을 고르고 저장 위치 선택. zip 에는 `대화.txt` · `대화.csv` · `files/`(사진·파일·음성 원본)가 들어가고, 보관 기간이 지난 첨부는 빠진 채 대화 줄 끝에 `[포함되지 않음: 사유]`로 표시됩니다. 한 번에 최근 2만 개까지 |
| 친구 소식 숨기기 | 소식 기능이 켜져 있을 때 친구 우클릭 → 소식 숨기기 |
| 키보드로 쓰기 | 채팅방에서 Alt+↑/↓ 메시지 고르기 → Shift+F10(또는 메뉴 키) 그 메시지의 메뉴 → Esc 해제. Ctrl+1~5 탭, Ctrl+K 빠른 이동 |
| 자동 재연결 | 서버 연결이 끊기면 1·2·4·8·10초 간격으로 스스로 다시 연결하고, 끊긴 사이 온 메시지를 열린 채팅방에 채워 넣습니다. 위쪽 배너의 '다시 연결'로 바로 시도할 수도 있습니다 |
| 큰 채팅방 | 최근 150개만 먼저 그리고, 위로 올리면 150개씩 더 보여 줍니다 (메시지 1000개 방도 0.15초 안에 열림) |
| 보내지 못한 메시지 | 연결이 끊긴 동안 보낸 글은 빨간 ! + '전송 실패'로 남습니다(앱을 꺼도 유지). ! 를 눌러 재전송 · 복사 · 삭제. 채팅 목록에도 '보내지 못한 메시지가 있습니다' |
| 동작 줄이기 | 더보기 › 상태·화면 › 동작 줄이기 — 녹음 표시 깜빡임·요약 진행 막대를 멈춥니다 |
| 조직도 → 연락처 보내기 | 조직도에서 사람 우클릭 → 연락처 보내기… → 보낼 채팅방 선택 |

## v5 기능 (업무용 메신저 필수 기능 조사 반영)

| 기능 | 쓰는 법 |
|---|---|
| 방해금지 | 더보기 › 방해금지 · 키워드 · 꾸미기 › 방해금지, 또는 트레이 아이콘 메뉴 › 알림 일시중지. 30분~직접 끌 때까지 알림을 멈추고, '근무 시간 밖에는 알림 끄기'(요일·시간), VIP(방해금지 중에도 알림을 받을 사람)를 정합니다. 안 읽은 수와 아이콘 깜박임은 그대로입니다 |
| 휴가 중 | 내 상태 › 휴가 중. 앱을 꺼도 조직도·친구 목록에 '휴가 중'으로 보입니다. 돌아오면 상태를 온라인으로 바꾸세요 |
| 방장 | 그룹방을 만든 사람이 방장입니다. 채팅방 위 대화상대 수 › 사람 옆 ⋯ › 방장 넘기기 · 내보내기. 방장이 나가면 가장 먼저 들어온 사람이 방장이 됩니다 |

| 안 읽은 사람 보기 | 말풍선 옆 읽음 숫자를 누르면 아직 안 읽은 사람이 보입니다 |
| 멘션 모아보기 | 채팅 탭 ⋯ › @ 나를 멘션한 메시지. 모든 채팅방에서 나를 부른 메시지를 모아 보고 바로 이동합니다 |
| 책갈피 | 말풍선 우클릭 › 책갈피. 채팅 탭 ⋯ › 책갈피에서 다시 찾아갑니다 |
| 입력 임시저장 | 쓰다 만 글은 채팅방을 닫아도 남고, 채팅 목록에 [임시저장]으로 보입니다 |

## 실행

Windows · macOS · Linux 모두 같은 명령입니다 (Windows 는 `python3` 대신 `py`). 설치 · 더블클릭 실행 · 실행 파일 만들기는
[CROSS_PLATFORM.md](CROSS_PLATFORM.md) 를 보세요.

```bash
python3 -m pip install -r requirements-kcs.txt   # 필수(PyQt5 · cryptography) + 권장(numpy · pypdf · anthropic)
python3 kcs.py doctor                  # 이 PC 점검
python3 kcs.py server                  # 서버
python3 kcs.py                         # 클라이언트

# 예전 명령도 그대로 됩니다
python3 server/chat/chat_server.py     # 서버 (기본 127.0.0.1:5555, DB: server_data/kakao.db)
                                       #   --no-briefing: 오늘의 브리핑 끄기, --no-link-preview: URL 미리보기 끄기
python3 client/kakao/app.py            # 클라이언트 (여러 개 실행 가능)
python3 client/kakao/app.py --user 홍길동 --host 127.0.0.1 --port 5555
python3 client/launcher/chat_launcher.py   # GUI 런처 (서버 + 클라이언트 관리)
```

### 친구 추가 (전화번호 · 이메일)
- 친구 탭 오른쪽 위 👤+ 버튼 → [전화번호] 또는 [이메일] 선택 → 입력 → 친구 추가
- 상대가 프로필 편집에 등록한 휴대폰 번호/이메일과 **정확히 일치**할 때만 찾습니다(일부만 입력해 목록을 훑을 수 없음). 번호는 하이픈·공백·+82 표기를 가리지 않고, 이메일은 대소문자를 가리지 않습니다.
- 추가한 친구는 '내가 추가한 친구'에 모이고, 우클릭 → 친구 삭제. 프로필 창의 [친구 추가]로 바로 등록할 수도 있습니다.
- 다른 사람이 나를 찾게 하려면: 내 프로필 → 편집 → 전화번호·이메일 입력

### 친구 목록에서 여러 명 골라 대화방 만들기
- **Shift + 클릭**(또는 Ctrl/⌘ + 클릭): 친구를 한 명씩 넣고 뺍니다. 고른 줄은 바탕색이 바뀝니다
- **Shift + 누른 채 끌기**: 처음(또는 원하는 사람)에서 Shift 를 누른 채 마우스를 누르고 아래로 끌면 그 사이 친구가 모두 선택됩니다. 목록 끝까지 끌면 저절로 넘어가며, 접혀 있는 '오프라인' 구역도 끝까지 끌면 모두 들어갑니다
- 아래에 'N명 선택 · 이름…' 줄이 나타나면 **[대화방 만들기]**(한 명이면 [1:1 채팅]) → 고른 사람이 체크된 대화상대 창에서 방 이름을 정하고 확인
- **오른쪽 클릭**으로도 됩니다: 친구 우클릭 → '대화상대로 선택' / '선택에서 빼기'. 고른 사람이 있으면 맨 위에 '선택한 N명과 대화방 만들기…'(고르지 않은 친구를 우클릭하면 '선택한 N명 + 그 친구 대화방 만들기…'), 빈 곳·구역 머리글 우클릭에도 같은 메뉴와 '선택 해제'가 나옵니다
- 선택 풀기: [선택 해제], Esc, 또는 Shift 없이 친구 클릭. AI 비서·내 프로필은 고를 수 없습니다

### 참여자 목록 보기
- 모든 채팅방(나와의 채팅 제외) 헤더 아래에 **참여자 줄**이 있습니다. 접혀 있을 때는 '대화상대 N명  나, 김철수, 박민수 …  ›' 한 줄로 보입니다
- **›** 버튼이나 줄 아무 곳을 누르면 펼쳐져 사진·이름이 나오고 화살표가 **⌄**로 바뀝니다. 다시 누르면 접힙니다 (사라지지 않습니다). 키보드는 Space·Enter
- 펼침/접힘은 방마다 기억합니다. 그룹 대화방을 새로 만들면 펼친 채로 열립니다. 방 메뉴(≡) → 대화상대 목록 펼치기/접기도 됩니다
- 사진을 누르면 프로필, [전체 보기]는 소속·방장 표시가 있는 전체 목록. 초대·나가기로 인원이 바뀌면 바로 반영됩니다

### 대화상대 초대

- 1:1 채팅방에서 초대하면 기존 대화상대 + 초대한 사람으로 **새 그룹 채팅방**이 만들어집니다

### AI 비서(RAG) 설정
- 검색: 질문자가 속한 방의 대화 + 본인이 올린 문서만 검색합니다(권한 필터).
- 답변 생성: `anthropic` 패키지와 API 자격 증명(`ANTHROPIC_API_KEY` 등)이 있으면 Claude(`claude-opus-5-5`)가 답변하고,
  없으면 검색 결과를 출처와 함께 보여주는 추출형으로 동작합니다.
- 환경 변수: `KCS_RAG_MODEL`(모델 변경), `KCS_RAG_LLM=off`(Claude 사용 안 함)

### AI 비서 ↔ 사내 포털(portal.kcins.co.kr) 연동
- 메신저에서 AI 비서에게 바로 질문하면(채팅탭 ✨ 버튼 → 1:1, 또는 그룹방에서 `@AI 비서`) 서버가 **사내 포털 RAG**에 물어 답을 가져오고,
  질문·답변은 **포털에 대화 기록으로 저장**됩니다. 포털이 응답하지 않으면 메신저 자료로 답하고(답 끝에 안내), 저장할 기록은
  `server_data/portal_outbox.db`에 보관했다가 포털이 돌아오면 자동으로 보냅니다.
- 서버(`python3 kcs.py server`)는 기본으로 연동합니다. 끄기: `--no-portal` 또는 `KCS_PORTAL=off`.
- 설정: `docs/portal.example.json`을 `server_data/portal.json`으로 복사해 토큰·API 경로를 채우거나, 환경 변수
  `KCS_PORTAL_URL` · `KCS_PORTAL_TOKEN` · `KCS_PORTAL_ASK_PATH` · `KCS_PORTAL_SAVE_PATH` · `KCS_PORTAL_STYLE`(kcs|openai)을 씁니다.
- 연결 점검(사내망에서): `python3 scripts/portal_check.py "연차 규정 알려줘"`
- 포털은 사내망에서만 열립니다(외부망에서는 403). 메신저 서버는 사내망 PC/서버에서 실행하세요.

- 엑셀 '사내전화번호' 시트의 부서 블록(직급·이름·계정·내선·휴대폰)과 겸직(`(*)`)을 읽습니다.
- 조직도는 회색 바닥 위에 **카드**로 나뉩니다(KCS AI · 그룹사 · 그룹마다 하나 · 게스트). 그룹사 카드 안에서는 왼쪽 선이 14개사가 그룹사 소속임을 보여 주고, 그룹사와 내 회사 아이콘은 네이비로 표시됩니다. 구성원 사진은 머리글 이름이 시작하는 위치에 맞춰 나옵니다.
- 조직도 탭은 맨 위에 **KCS AI 지식봇**, 그 아래 **그룹사** 머리글(누르면 접힘) 밑으로 한 단계 들여쓰기해 한국지주 · 한국컴퓨터 · 한네트 · 로지시스 · 케이씨티 · 케이씨에스 등 지주사와 계열사 13곳이 **모두 같은 단계**로 나오고, 맨 아래는 예전과 같이 게스트입니다.
- 기본 구성(`--layout groupware`)은 사내 그룹웨어 조직도와 같습니다: **그룹사 › 케이씨에스 › 김광묵 대표이사 + 관리팀 · 마케팅팀 · 신사업팀 · MICE사업팀 · 영업1부 · 영업2부 · 영업3부 · 기술연구소1실 · 2실 · 3실** (부서는 접힌 채 시작, 👤N › 칩을 누르면 구성원 목록). 부서를 펼치면 **부서장 → 팀(예: 1팀(Tandem), AI/AX 솔루션사업팀) → 팀원** 순서로 나옵니다. 엑셀에 예전 이름으로 남은 조직은 `UNIT_RENAMES`로 바꿉니다(연구1실 '2팀(SI)' → 'AI/AX 솔루션사업팀'). **겸직:** 엑셀 이름·직급의 `(*)` 표시자는 표시된 모든 조직에 나오고(같은 부서의 다른 팀도 각각), 엑셀이 첫 팀 안에 적어 둔 부서장(본부장·실장·상무이사 등)은 부서 바로 아래와 그 팀 모두에 나옵니다. 주소속이 아닌 곳에는 '겸직' 표시가 붙습니다(2026-09-01 엑셀 기준 이동현·엄태식·문동민·조종익·윤성목·김성준). 주소속 보정은 `GROUPWARE_OVERRIDES`(엄태식→신사업팀 · 연구1실은 겸직으로 유지). 그 밖의 소속은 엑셀 그대로입니다(류병두 매니져: 엑셀대로 MICE사업팀 — 그룹웨어 화면은 관리팀 5 · MICE사업팀 2명이지만 화면에 이름이 없어 누가 옮겼는지 알 수 없으므로 보정하지 않습니다). **인원 수:** 부서·팀 칩은 그곳에 나오는 사람 수(겸직 포함)이고, 회사 총원은 겸직자도 1명으로 셉니다(부서 소속 52명). 관리자 계정(KCS관리자, 아이디 `kcs_administrator`)은 다른 사람의 조직도에는 보이지 않고, 관리자 본인으로 로그인하면 관리자를 포함한 전체가 보입니다. 엑셀 그대로의 부 › 본부 › 팀 3단계가 필요하면 `--layout raw`.
- 그룹 구조는 한국지주 사업보고서(DART, 2025-12-31 기준) '계열회사 현황' 13곳: **한국지주(지주회사) → 상장 한국컴퓨터 · 한네트 · 로지시스 · 케이씨티 · 케이씨에스 → 비상장 한국문학사 · 한국상역개발 · 상화원 · 제주상화원 · 한상개발 · 상화공익 → 해외 현지법인 KCI VINA(베트남) · Pacom International(한국컴퓨터 100%)**. 대표전화·홈페이지는 DART 기업정보 기준이고, 비상장사는 확인된 상장 여부·지분만 표시합니다. 구성원이 없는 계열사는 접힌 채로 나옵니다.
  계열사를 바꾸거나 더할 때: `--affiliates "한국컴퓨터,한네트,로지시스,케이씨티,케이씨에스,새계열사"`
- `server_data/org.json` 에는 개인 연락처가 들어가므로 git 에 올라가지 않습니다(.gitignore).
- 실제 조직도를 쓰면 예전 데모 사용자(홍길동 등)는 '게스트'로 표시됩니다. 처음 한 번은 로그인 창 아래 **[처음 사용하시나요? · 처음 사용 등록]**을 눌러 **소속 회사를 고르고(필수)** 이름·이메일 주소·비밀번호를 등록합니다(회사 목록은 서버에서 받아 옵니다, 사번 칸은 없습니다). 그다음부터는 **이메일과 비밀번호만** 넣고 로그인합니다(예전에 사번으로 등록한 계정은 사번·이름·사내 계정으로도 로그인됩니다). 등록하지 않은 아이디로 로그인하면 등록 화면으로 바로 넘어가고 입력한 이메일이 옮겨집니다. 조직도에 이미 있는 사람은 조직도와 같은 소속을 골라야 하고, 조직도에 적힌 회사 이메일과 같아야 하며, 이름·이메일이 이미 등록돼 있으면 등록되지 않습니다. macOS 에서는 로그인 창 · 메인 창 · 채팅방 별도 창 위쪽에 회색 제목 표시줄이 따로 없고, 사이드바·헤더 색이 창 맨 위까지 이어집니다(카카오톡과 같은 모양, 창은 맨 위 줄을 끌어 옮깁니다). 아이디(이메일) 칸(로그인 · 처음 사용 등록 · 비밀번호 재설정)에 커서가 오면 한글 상태였어도 입력이 바로 **영문**으로 바뀝니다(macOS 입력 소스 · Windows 한/영). 비밀번호 칸의 눈 아이콘을 누르면 입력한 비밀번호를 확인할 수 있습니다. 로그인 창의 [이메일·비밀번호 저장]을 켜면 다음 실행 때 비밀번호 칸을 비워 둔 채 로그인되고, [자동 로그인]을 켜면 로그인 창 없이 바로 들어갑니다. PC에는 비밀번호 원문이 아니라 30일 동안 쓰는 로그인 토큰만 `~/.kcs_messenger/saved_login.json`(본인만 읽기)에 저장됩니다. 끄려면 더보기 맨 위 [계정 · 로그아웃](또는 트레이 아이콘 메뉴 → 로그아웃). **간편 로그아웃:** 왼쪽 아래 내 사진을 우클릭 → [로그아웃]을 누르면 확인 창 없이 바로 로그아웃됩니다. 런처(`chat_launcher.py`)의 [채팅창 열기]는 창마다 **처음 로그인하는 상태**의 로그인 창을 띄웁니다(`app.py --no-auto-login`): 아이디·비밀번호 칸이 비어 있고 저장된 로그인·최근 아이디를 쓰지 않으므로, 아이디와 비밀번호를 넣어야 들어가고 창마다 다른 사람으로 로그인할 수 있습니다. 배포용 서버(`server/chat/chat_server.py`)는 비밀번호 없는 로그인을 받지 않습니다(구버전 클라이언트용 `--allow-passwordless`). 비밀번호를 잊으면 로그인 창 아래 **[비밀번호를 잊으셨나요? · 비밀번호 재설정]**에서 사번 · 가입할 때 등록한 이메일 · 새 비밀번호를 넣어 직접 바꿉니다(바꾸면 그 계정의 저장된 자동 로그인은 모두 해제, 이메일이 틀리면 로그인 실패와 같이 5번이면 5분 잠김). 관리자 계정은 이메일만으로는 바꿀 수 없습니다(다른 그룹 관리자나 서버 PC 에서). 조직도에 이메일이 미리 들어 있는 사람은 [처음 사용 등록]에서 그 회사 이메일을 그대로 넣어야 등록됩니다(이름만 알고 남의 계정을 가져가지 못하게). 조직도에 사번만 있고 이메일이 없으면 관리자가 이메일을 먼저 등록해 줘야 합니다. 다른 사람의 이메일은 프로필에 보이지 않습니다(본인 · 관리자만). 가입 이메일도 모르면 관리자가 `python3 scripts/set_password.py <아이디>`로 새로 정하거나 `--clear`로 지워 [처음 사용 등록]을 다시 하게 합니다. 5번 틀리면 5분 동안 그 아이디로 로그인할 수 없습니다.
- **프로필 기본 사진:** `python3 scripts/import_org_photos.py "~/Downloads/연락처 및 조직도(20260901).xlsx"` 는 엑셀 좌석배치도 시트(3층·4층·6층)의 사진을 그 아래 이름 칸과 짝지어 사진이 없는 구성원의 프로필 사진으로 넣습니다(엑셀에서 잘라 보여 주는 부분만, 256px 정사각형). 본인이 직접 올린 사진은 그대로 두고, 바꾸려면 `--force`, 저장 없이 짝만 확인하려면 `--dry-run`. 서버가 켜져 있어도 되며 접속 중인 사람은 다시 로그인하면 보입니다. 2026-09-01 엑셀에는 양진우·류병두·김현경의 사진이 없습니다.
- 조직도는 왼쪽 메뉴 '조직도' 탭에 있고, 창을 넓히면(860px 이상) 왼쪽에 항상 펼쳐집니다. 프로필에서 내선·휴대폰·계정·겸직을 볼 수 있습니다.

### 관리자 권한
- 관리자 계정은 **KCS관리자**(사내 계정 `kcs_administrator`)입니다. `server_data/org.json` 의 `admins` 에 적힌 사람은 서버를 켤 때마다 관리자가 되고, 서버 PC 에서 `python3 scripts/set_admin.py <아이디>`(해제는 `--off`, 목록은 `--list`)로도 지정합니다.
- 관리자는 두 종류입니다. **그룹 관리자**는 모든 계열사 구성원을, **회사 관리자**는 자기 회사 구성원만 관리합니다(목록에도 자기 회사만 보임). 관리자 지정과 전체 공지는 그룹 관리자만 할 수 있습니다. 회사 관리자 지정: 계정 관리 창 [관리자 지정]에서 범위(그룹 전체 / 회사)를 고르거나 `python3 scripts/set_admin.py <아이디> --company 케이씨에스`.
- 관리자로 로그인하면 **더보기 → 관리자 → 계정 관리** 줄이 생깁니다(다른 사람에게는 보이지 않고, 서버도 요청마다 관리자인지·범위 안인지 다시 확인합니다). 창 제목에 범위가 나옵니다: '관리자 · 계정 관리 (그룹 전체)' / '(케이씨에스)'.
- **서버 주소 정하기 (그룹 관리자만)** — 로그인 창에는 서버 설정이 없습니다. 그룹 관리자(예: KCS관리자, `kcs_administrator`)로 로그인하면 더보기 맨 아래 **정보** 구역이 보이고(다른 사람에게는 구역째 보이지 않음), **서버 주소 · 포트**를 입력하고 [저장]하면 이 PC 에서 다음 로그인부터 그 주소로 연결합니다(`~/.kcs_messenger/server.json`). 주소가 틀려 아무도 접속하지 못하면 관리자가 `python3 kcs.py client --host <서버주소> --port 5555` 로 한 번 접속해 정보에서 다시 저장하면 됩니다. 연결에 실패하면 [다시 시도] [종료]만 나오고 '관리자에게 문의' 안내가 보입니다.
- **편집 모드 (구성원 정보 바로 고치기)** — 관리자(예: KCS관리자, `kcs_administrator`)로 로그인하면 조직도 탭 위쪽에 **연필 버튼(편집 모드)**이 생깁니다. 켜면 헤더 아래에 '편집 모드' 안내 줄이 나오고, 구성원을 누르면(두 번 눌러도) 채팅 대신 **구성원 정보 창**이 열립니다. 소속 회사 · 부서 · **팀** · 직급 · 사번 · 사내 계정 · 내선 · 휴대폰 · 이메일을 고치고 [저장]하면 바뀐 칸만 서버에 보내고, 모든 사람 화면에 바로 반영됩니다(이름은 바꿀 수 없음). 끝내려면 안내 줄의 [끝내기] 또는 연필 버튼을 다시 누릅니다. **우클릭으로도 됩니다:** 조직도 · 친구 목록의 사람을 우클릭하거나 프로필 창 아무 곳이나 우클릭 → **정보 수정 (편집 모드)…** (조직도에서는 편집 모드가 같이 켜집니다). 회사 관리자는 자기 회사 사람만, 봇은 고칠 수 없고, 사번 · 이메일이 겹치는 등 서버가 거절하면 알림 창으로 이유를 보여 줍니다.
- **조직도 그룹 만들기** — 그룹 관리자(예: KCS관리자)로 로그인하면 조직도 탭 위쪽에 **[+] 그룹 만들기** 버튼이 생깁니다. 그룹 이름 · 설명을 넣고 회사와 상관없이 구성원을 골라 체크하면, 모든 사람의 조직도 '그룹' 구역에 바로 나타납니다(예: 경영위원회, 양자암호 TF). 그룹 머리글을 우클릭하면 **그룹 수정… / 위로 이동 / 아래로 이동 / 그룹 삭제**(구성원 계정은 그대로). **순서 바꾸기:** 맨 위 **KCS AI · 그룹사는 고정**이고, 그 아래 만든 그룹들과 게스트는 그룹 관리자만 머리글을 마우스로 잡고 끌어 원하는 자리에 놓으면 됩니다(끌 수 있는 머리글에 마우스를 올리면 손 모양 커서가 나옵니다). 끄는 동안 머리글이 카드처럼 떠서 따라오고, 다른 그룹들이 미리 비켜 서서 놓을 자리(점선 칸)를 보여 줍니다. 목록 끝으로 끌면 저절로 스크롤되고, Esc 를 누르면 취소됩니다(우클릭 → 위로/아래로 이동도 가능). 일반 사용자와 회사 관리자는 순서를 바꿀 수 없고 서버도 거부합니다. 바뀐 순서는 모든 사람의 조직도에 똑같이 적용되고 서버를 다시 켜도 유지됩니다. 검색 중에는 끌 수 없습니다. 회사 관리자와 일반 사용자에게는 버튼이 보이지 않습니다.
- **구성원 등록·조회·수정·삭제**
  - **구성원 등록…** — 이름(나중에 못 바꿈) · 소속 회사 · 부서 · 직급 · 사번 · 사내 계정 · 내선 · 휴대폰 · 이메일. 비밀번호 없이 만들어지므로 그 사람은 로그인 창의 [처음 사용 등록]으로 비밀번호를 정합니다(같은 회사·이름으로).
  - **조회 · 수정…**(행 두 번 클릭도) — 정보를 보고 고칩니다. 사번·사내 계정·이메일은 다른 사람과 겹칠 수 없습니다.
  - **삭제** — 조직도·친구 목록에서 빠지고 로그인할 수 없습니다(접속 중이면 바로 끊김). 주고받은 대화는 남고, **삭제한 구성원 보기**를 켜면 [복원]할 수 있습니다.
  - 관리자가 등록·수정·삭제한 구성원은 서버를 다시 켜도 `org.json`(엑셀에서 가져온 조직도)이 되돌리지 않습니다.
- 계정 관리 창: 이름·소속·사번·이메일로 검색하고, 고른 사람에게
  - **비밀번호 재설정…** — 새 비밀번호를 두 번 입력. 그 사람의 자동 로그인은 해제됩니다.
  - **등록 초기화** — 비밀번호를 지워 [처음 사용 등록]부터 다시 하게 합니다(사번·이메일은 남김).
  - **사용 중지 / 해제** — 퇴사자 등. 로그인할 수 없고, 접속 중이면 "사용이 중지된 계정입니다" 안내와 함께 바로 로그인 화면으로 돌아갑니다. 자기 계정은 중지할 수 없습니다.
  - **관리자 지정 / 해제** — 마지막 관리자는 해제할 수 없습니다.
- **전체 공지…** — 지금 접속 중인 모든 사람에게 '관리자 공지' 창과 알림으로 바로 보냅니다(1000자 이내, 접속하지 않은 사람에게는 가지 않습니다).
- **파일 전송 보안… (그룹 관리자만)** — 외부 유출을 막는 첨부 정책입니다. 계정 관리 창의 [파일 전송 보안…]
  - **정책**: 켜기/끄기, 막을 형태(실행 파일 · 압축 · 데이터베이스 · 인증서/키 · 소스 코드 · 문서 · 이미지 · 동영상 · 음성), 막을 확장자(`hwp, dwg`), 막을 파일 이름(한 줄에 하나, `*대외비*`; `*` 가 없으면 이름에 들어 있으면 막음). 형태는 파일 내용으로도 판별해서 확장자를 바꿔도 잡힙니다. 저장하면 모든 사람에게 바로 적용됩니다.
  - **승인 요청**: 막힌 파일을 보내려는 사람이 사유를 적어 요청하면 관리자에게 알림이 오고 '승인 요청 N' 탭에 쌓입니다. [파일 받아 확인…]으로 내용을 보고 [승인하고 보내기]를 누르면 그때 요청한 사람 이름으로 그 대화방에 전송됩니다. '같은 파일 다시 허용'에 일수를 넣으면 그 사람이 같은 파일(내용이 똑같은 파일)을 그 기간 동안 다시 보낼 수 있습니다. [반려]하면 보관하던 파일은 지워지고, 메모가 요청한 사람에게 전달됩니다.
  - **예외**: 특정인에게 특정 파일 이름(예: `*.zip`, `설계도_v3.dwg`)을 1~365일 동안 풀어 줍니다.
- 관리자가 한 일은 서버 로그에 `관리자 <누가>: <무엇> <대상>` 으로 남습니다.
