# 12. KCS Ink 리디자인 (2026-10-10)

사용 스킬: ui-ux-pro-max(디자인 시스템 검색, Minimalism & Swiss · 업무용 밀도 7) · impeccable(Operate 모드, craft floor 금지 목록) ·
taste-skill-kr(재설계 원칙, 한글 규칙) · frontend-design(토큰 계획 → 기본값 점검 → 시그니처 하나) · ui-styling(토큰 체계, 상태 규칙).

PRODUCT.md가 없어 사용자 인터뷰 대신 브리프와 기존 코드에서 맥락을 추론했다: ㈜케이씨에스 사내 메신저, 업무 시간 내내 켜 두는 도구,

## 서체

앱 글꼴(2026-10-15, Pretendard 대체): 영문 · 숫자 · 기호는 **Poppins**(Indian Type Foundry, SIL OFL 1.1, Google Fonts 배포본, `assets/fonts/Poppins-OFL.txt`) — 영문은 **SemiBold** 한 굵기로 보이도록 SemiBold · Bold 두 파일만 넣어 300~600 은 SemiBold, 700~900 은 Bold 가 된다. 한글 · 한자는 **KoPub World 돋움**(Light · Medium · Bold, 한국출판인회의 무료 배포 · 임베딩 허용, `KoPubWorld-LICENSE.txt`). Poppins 에 한글이 없어 Qt 가 한글만 KoPub 돋움으로 내려 그린다(`osenv.ui_font_families()` 순서). 모두 TrueType 이라 Windows ClearType 힌팅이 그대로 살아 Pretendard(CFF OTF)보다 작은 글자가 또렷하다. 코드에서는 `theme.font(size, weight=300~900)`(글꼴마다 가장 가까운 굵기 파일), QSS 에서는 `font-weight: 300~700`.

이전: Pretendard v1.3.9 정적 글꼴 300~900 일곱 굵기(2026-10-10 ~ 10-14) → JetBrains Mono 파생 KCS Talk Mono(2026-10-15 오전, 같은 날 Poppins 로 교체).

입력 컨트롤(2026-10-10): 콤보박스 화살표 칸과 시간 · 날짜 · 숫자 칸의 위아래 단추는 테두리 없는 쉐브론(`widgets.input_controls_qss()`, 앱 전역). 콤보 목록은 칸을 덮지 않고 바로 아래 같은 너비로 열리며, 줄 높이 30px · 둥근 선택 줄 · 연한 테두리를 쓰고 macOS 진한 창 윤곽선은 끈다(`widgets.install_input_controls()`).

탭 검색 칸(2026-10-10): 조직도 · 친구 탭 검색 칸은 `TabHeader.add_search()`로 헤더 안(부제목 아래 10px · 구분선 위 12px)에 둔다. 헤더 밖 바로 아래에 두면 칸 윗변이 구분선에 붙어 겹쳐 보였다. 채팅 탭은 폴더 줄 아래라 위아래 8px 띄움. 검색 칸 높이는 34px 이상이라 둥근 모서리 16px 가 그려진다(모서리가 높이 절반을 넘으면 Qt 는 네모로 그린다), 포커스는 네이비 1px 테두리.

팝업 제목 표시줄(2026-10-11): 모든 대화상자 · 알림 상자는 macOS 제목 표시줄을 본문 색으로 칠하고 창 모양을 앱 테마(밝게=Aqua, 어둡게=DarkAqua)에 맞춘다(`macos.match_title_bar`, 앱 전역 `widgets.install_dialog_title_bars`). 시스템이 다크 모드여도 밝은 테마 팝업의 제목 표시줄이 검게 나오지 않는다. 다른 배경 창은 속성 `titleBarColor`(통화 창 = 위쪽 배경색). 파일 · 색 · 글꼴 선택 창은 macOS 기본 창 그대로.

친구 탭 내 부서 줄(2026-10-11): 첫 줄 "이름(굵게) 직함(보조색)" 예) **강태영** 책임, 둘째 줄 팀(없으면 부서) · 지금 일정. 예전에는 둘째 줄에 "책임 · AI/AX 솔루션사업팀"으로 직함과 팀을 함께 적었다.

팝업 위치(2026-10-11): 모든 대화상자는 띄운 창(메신저 메인 창 · 대화방 창, 부모가 없으면 보이는 메인 창) 가운데에 연다(`widgets.center_on_messenger`, 화면 밖으로 나가면 안쪽으로 붙임). 버튼 옆 목록(Qt.Popup)과 속성 `keepPosition` 창은 제외. 프로필 편집 맨 위에는 사번 카드(보기만), 폼 칸은 창 너비만큼 늘린다(macOS QFormLayout 기본은 칸이 좁게 고정).

겸직 표시(2026-10-11): 조직도 구성원 줄의 "겸직"은 이름(·직함) 바로 옆 작은 알약(연한 네이비 바탕 `bg_selected`, 글자 라이트 `yellow` 9.2:1 · 다크 `link` 5.3:1, 캡션 굵게, `org_tab.concurrent_tag`), 마우스를 올리면 주소속. 예전에는 줄 끝에 줄 높이만큼 늘어난 테두리 상자였다.

파일 전송 보안(2026-10-11): 막힌 파일 창은 경고 아이콘 대신 `file` 아이콘을 `danger_text` 로, 파일 이름 · 막힌 이유를 `bg_selected` 카드 한 장에 모은다(빨간 테두리 · 옆 줄 없음). 사유를 적어야 주 버튼 [승인 요청]이 켜진다. 관리자 창은 탭 3개(정책 · 승인 요청 N · 예외), 처리한 요청은 `text_hint` 로 흐리게.

날짜 고르기 달력(2026-10-11): Qt 기본 달력(초록 동그라미 화살표, 원색 빨강 주말 · 토요일도 빨강, 다른 달 날짜도 같은 색, 네모 선택 칸, '10월 2026' 머리글)을 `date_picker.DatePickerCalendar` 로 바꿨다. 머리글 '2026년 10월' + 가는 꺾쇠 ‹ › + 테두리 없는 [오늘], 요일 줄은 띠 없이 캡션 글자(일 `calendar_sun` · 토 `calendar_sat` · 평일 `text_hint`), 선택한 날은 강조색 동그라미 + `on_accent` 굵은 글자, 오늘은 강조색 1.5px 고리, 앞뒤 달 날짜는 38% 흐리게, 칸 약 40px. 달력 팝업을 쓰는 모든 날짜 칸(일정 · 할 일 기한 · 예약 메시지 · 대화 저장 기간)에 `widgets.use_date_picker` 가 자동으로 끼운다.
`theme.load_bundled_fonts()` 가 첫 글꼴 조회 때 한 번 등록한다. 설치된 시스템 서체를 쓰던 때보다 한글·영문·숫자 폭이 고르다.
탭 제목은 22px 굵게, 자간 -0.4px.

## 모양

- **말풍선**: 카카오 꼬리를 없앴다. 묶음 첫 말풍선은 말한 사람 쪽 위 모서리만 4px, 나머지는 17px (`corner_path`).
  받은 말풍선은 테두리 없이 아래 1px 그림자 하나로 뜬다 (높이는 한 가지 방법만).
- **시그니처, 날짜 구분선**: 날짜 칩 양옆으로 가는 잉크 선이 종이를 가른다 (`ChipRow.paintEvent`). 시스템 안내는 선 없이 칩만.
- **입력창**: 위 경계선이 있던 흰 띠 대신, 종이 위에 뜬 16px 둥근 카드. 입력 중에는 테두리가 잉크색이 된다.
  전송 버튼은 10px 모서리의 잉크 버튼이고, 비활성일 때는 테두리 없는 옅은 면이다.
- **아바타**: 원색 빨강·초록 대신 채도를 누른 잉크 톤 9가지. 위가 12% 밝은 세로 농담 (흰 굵은 이니셜 4.3:1 이상).
- **지운 장식** (impeccable 금지 목록): 탭 제목 앞 세로 강조 막대, 일정 카드 왼쪽 6px 색 줄무늬 (→ 일정 색은 달력 아이콘 색으로).
- **전역 QSS**: 입력칸 8px · 포커스 잉크색, 메뉴 10px 모서리 · 항목 6px · 구분선, 툴팁 반전색, 스크롤바 잉크 회색.
